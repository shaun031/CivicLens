# CivicLens Roadmap

All implementation through Phase 13 is local-first. Exact scope may be refined before each phase without moving cloud deployment earlier.

| Phase | Focus |
|---:|---|
| 0 | Project initialization and local development foundation |
| 1 | AWS infrastructure foundation (local CDK definitions only) |
| 2 | Authentication and User Roles (local implementation and Cognito definitions) |
| 3 | Citizen Frontend and User Experience |
| 4 | Complaint Submission System and Evidence Management |
| 5 | Complaint Dashboard, Search, Filtering, and Geographic Incident Discovery |
| 6 | Multi-Modal Duplicate Complaint Detection Engine |
| 7 | Intelligent Complaint Clustering and Master Incident Management (implemented locally; cloud unverified) |
| 8 | Dynamic Incident Priority Scoring and Explainable Urgency Ranking (implemented locally) |
| 9 | Intelligent Department Assignment and Municipal Work Allocation (implemented locally) |
| 10 | Automated Event-Driven AWS Workflows, Notifications, and Escalation (next; not started) |
| 11 | Municipal administration dashboard and analytics (detailed scope pending brief) |
| 12 | Events, queues, escalation, and notifications (provisional scope) |
| 13 | End-to-end hardening, security, observability, and deployment readiness |
| 14 | User-initiated AWS deployment and cloud verification |

Phase14 begins only after local acceptance, cost/template review and explicit approval. Phases0–9
are implemented locally, subject to actual verification in PHASE_PROGRESS.md. The Phase9 brief fixes
the next phase as **Phase10 — Automated Event-Driven AWS Workflows, Notifications, and Escalation**.
It has not started. Other future detailed scopes remain provisional. Deployment stays in Phase14.
